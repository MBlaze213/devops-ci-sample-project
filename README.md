# DevOps CI/CD Sample Project

## Project Overview
This project demonstrates a basic CI/CD pipeline using GitHub Actions, Docker, and Kubernetes. It includes unit testing with PyTest and BDD testing with Behave.

## Technologies Used
- Python 3.11
- PyTest for unit testing
- Behave for BDD testing
- Docker for containerization
- Kubernetes for deployment
- GitHub Actions for CI/CD automation
