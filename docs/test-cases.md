# User Stories

## Epic: User Authentication

### Story 1: User Login
- As a user, I want to log in so that I can access my dashboard.
- Acceptance Criteria:
  - User must enter valid username and password.
  - On successful login, user is redirected to dashboard.
  - On failure, show error message.

### Story 2: User Registration
- As a new user, I want to register an account.
- Acceptance Criteria:
  - User provides username, email, password.
  - User receives confirmation email.
